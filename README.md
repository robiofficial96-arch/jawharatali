# Jawharat Ali (جوهرة علي) - Manpower Solutions Saudi Arabia

Official corporate website for **Jawharat Ali**, a licensed Saudi Arabian manpower supply agency based in Makkah. Supplying vetted cleaners, construction labor, drivers, hospitality staff, and MEP technicians across the Kingdom with 100% Qiwa and MHRSD compliance.

## ✨ Features

- **Executive Corporate Design**: Pure white background `#FFFFFF`, brand crimson red `#C7222A`, and charcoal slate `#3E3E3E`.
- **Bespoke Commercial Photography**: High-resolution photography of real Saudi workforce professionals against the King Abdullah Financial District (KAFD) Riyadh skyline.
- **Multilingual Support (3 Languages)**: Full dynamic switching for English (EN), Arabic (AR with complete RTL layout), and Bengali (BN).
- **Responsive Mobile Layout**:
  - Hero displays only the workforce photo on mobile screens (< 768px).
  - App-style fixed bottom navigation bar (Home, Categories, About Us, Why Us, Contact) with active state indicators.
  - Collapsible mobile drawer with hamburger menu (`☰`).
- **6 Distinct Pages**:
  - `index.html`: Home & Executive Overview
  - `about.html`: Corporate Profile
  - `services.html`: 6 Sector Categories with Filter Tabs
  - `why-us.html`: Saudi Vision 2030, Qiwa, & Labor Law Compliance
  - `process.html`: 4-Step Onboarding & Deployment Workflow
  - `contact.html`: Quotation Request Form & Direct WhatsApp Dispatch

## 🚀 Getting Started

To view the website locally, run:

```bash
# Using Python
python -m http.server 3000

# Open in browser:
http://localhost:3000
```
